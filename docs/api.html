dbt 项目管理 API

DataPilot 后端接口文档 — 所有接口前缀：/api/dbt

POST /api/dbt/projects

说明

创建新的 dbt 项目。

请求 Body (JSON)

字段类型必填说明
namestring是项目名称，唯一，最长 255 字符
descriptionstring否项目描述

请求示例

curl -X POST http://localhost:3010/api/dbt/projects \
  -H "Content-Type: application/json" \
  -d '{"name": "analytics_project", "description": "核心分析项目"}'

成功响应 201

{
  "id": 1,
  "name": "analytics_project",
  "description": "核心分析项目",
  "status": "active",
  "createdAt": "2026-06-05T10:00:00.000Z",
  "updatedAt": "2026-06-05T10:00:00.000Z",
  "deletedAt": null
}

错误响应

400 参数验证失败

409 项目名称已存在 {"error": "Project name already exists"}

POST /api/dbt/projects/:id/directories

说明

在项目内创建目录。系统自动计算 path 和 depth。

请求 Body (JSON)

字段类型必填说明
namestring是目录名，仅允许字母、数字、下划线、连字符、点
parentIdnumber | null否父目录 ID，null 或不传表示根目录

请求示例

curl -X POST http://localhost:3010/api/dbt/projects/1/directories \
  -H "Content-Type: application/json" \
  -d '{"name": "models", "parentId": null}'

成功响应 201

{
  "id": 1,
  "projectId": 1,
  "parentId": null,
  "name": "models",
  "path": "models",
  "depth": 0,
  "sortOrder": 0,
  "createdAt": "...",
  "updatedAt": "...",
  "deletedAt": null
}

创建嵌套目录示例

curl -X POST http://localhost:3010/api/dbt/projects/1/directories \
  -H "Content-Type: application/json" \
  -d '{"name": "staging", "parentId": 1}'

结果：path = "models/staging"，depth = 1

PUT /api/dbt/projects/:id/directories/:dirId

说明

重命名或移动目录。重命名/移动时，系统自动级联更新所有子目录和文件的 path。

请求 Body (JSON)

字段类型说明
namestring新目录名（重命名）
parentIdnumber | null新的父目录 ID（移动）

重命名示例

curl -X PUT http://localhost:3010/api/dbt/projects/1/directories/2 \
  -H "Content-Type: application/json" \
  -d '{"name": "staging_new"}'

移动示例

curl -X PUT http://localhost:3010/api/dbt/projects/1/directories/2 \
  -H "Content-Type: application/json" \
  -d '{"parentId": 5}'

错误响应

400 不能移动到自身或后代目录 {"error": "Cannot move directory to itself or its descendant"}

POST /api/dbt/projects/:id/files

说明

创建文件。系统根据扩展名自动检测 fileType，自动计算 size 和 path。支持的类型：sql, yml, yaml, md, py, csv, json, txt。

请求 Body (JSON)

字段类型必填说明
namestring是文件名（含扩展名）
contentstring否文件内容，默认空字符串
directoryIdnumber | null否所属目录 ID，null 表示项目根目录

请求示例

curl -X POST http://localhost:3010/api/dbt/projects/1/files \
  -H "Content-Type: application/json" \
  -d '{"name": "stg_users.sql", "directoryId": 2, "content": "SELECT * FROM users"}'

成功响应 201

{
  "id": 1,
  "projectId": 1,
  "directoryId": 2,
  "name": "stg_users.sql",
  "path": "models/staging/stg_users.sql",
  "content": "SELECT * FROM users",
  "fileType": "sql",
  "size": 20,
  "createdAt": "...",
  "updatedAt": "...",
  "deletedAt": null
}

POST /api/dbt/versions

说明

创建 dbt Core 版本，定义适配器包和 Python 依赖。

请求 Body (JSON)

字段类型必填说明
namestring是版本名称，唯一，最长 255 字符
versionstring是语义化版本号，最长 50 字符
adapterPackagesarray是适配器包列表，至少 1 个
adapterPackages[].namestring是适配器包名称
adapterPackages[].versionstring是适配器包版本
adapterPackages[].supportedDatabasesstring[]是支持的数据库类型列表
dependenciesarray是Python 依赖列表，至少 1 个
dependencies[].namestring是依赖包名称
dependencies[].versionstring是依赖包版本

请求示例

curl -X POST http://localhost:3010/api/dbt/versions \
  -H "Content-Type: application/json" \
  -d '{
    "name": "dbt-core-1.8",
    "version": "1.8.0",
    "adapterPackages": [
      {
        "name": "dbt-mysql",
        "version": "1.8.0",
        "supportedDatabases": ["mysql5", "mysql8"]
      }
    ],
    "dependencies": [
      { "name": "dbt-core", "version": "1.8.0" }
    ]
  }'

成功响应 201

{
  "id": 1,
  "name": "dbt-core-1.8",
  "version": "1.8.0",
  "adapterPackages": [{ "name": "dbt-mysql", "version": "1.8.0", "supportedDatabases": ["mysql5", "mysql8"] }],
  "dependencies": [{ "name": "dbt-core", "version": "1.8.0" }],
  "status": "active",
  "createdAt": "2026-06-06T10:00:00.000Z",
  "updatedAt": "2026-06-06T10:00:00.000Z",
  "deletedAt": null
}

错误响应

400 参数验证失败

409 版本名称已存在

POST /api/dbt/connections

说明

创建数据库连接。密码使用 AES-256-GCM 加密存储。

请求 Body (JSON)

字段类型必填说明
namestring是连接名称，唯一，最长 255 字符
databaseTypestring是数据库类型：mysql5、mysql8、starrocks、postgresql
hoststring是主机地址
portnumber是端口号，1-65535
databaseNamestring是数据库名称
schemaNamestring否Schema 名称
usernamestring是用户名
passwordstring是密码（明文传入，服务端加密存储）
extraConfigobject否额外配置，键值对

请求示例

curl -X POST http://localhost:3010/api/dbt/connections \
  -H "Content-Type: application/json" \
  -d '{
    "name": "prod_mysql",
    "databaseType": "mysql8",
    "host": "10.0.0.1",
    "port": 3306,
    "databaseName": "analytics",
    "username": "dbt_user",
    "password": "secret123"
  }'

成功响应 201

{
  "id": 1,
  "name": "prod_mysql",
  "databaseType": "mysql8",
  "host": "10.0.0.1",
  "port": 3306,
  "databaseName": "analytics",
  "schemaName": null,
  "username": "dbt_user",
  "status": "active",
  "createdAt": "2026-06-06T10:00:00.000Z",
  "updatedAt": "2026-06-06T10:00:00.000Z",
  "deletedAt": null
}

错误响应

400 参数验证失败

409 连接名称已存在

500 加密密钥未配置（DBT_ENCRYPTION_KEY）

POST /api/dbt/projects/:id/import

说明

上传 ZIP 压缩包导入 dbt 工程。系统解析 ZIP 中的目录结构和文件内容，存入数据库。dbt_project.yml 和 packages.yml 会被自动跳过。导入操作在数据库事务中执行，失败时全部回滚。

请求 (multipart/form-data)

字段类型说明
fileFileZIP 压缩包，最大 50MB

请求示例

curl -X POST http://localhost:3010/api/dbt/projects/1/import \
  -F "file=@my_dbt_project.zip"

成功响应 200

{
  "directories": 12,
  "files": 35
}

错误响应

400 文件格式错误 {"error": "Invalid file format, only ZIP is supported"}

413 文件过大 {"error": "File size exceeds limit (50MB)"}

404 项目不存在 {"error": "Project not found"}

GET /api/dbt/projects/:id/export

说明

将项目导出为标准 dbt 工程目录结构的 ZIP 文件。

请求示例

curl -O http://localhost:3010/api/dbt/projects/1/export

成功响应 200

返回 ZIP 文件下载。

响应头值
Content-Typeapplication/zip
Content-Dispositionattachment; filename="project_name.zip"

错误响应

404 {"error": "Project not found"}
