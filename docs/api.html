dbt 项目管理 API

DataPilot 后端接口文档 — 所有接口前缀：/api/dbt

POST /api/dbt/projects

说明

创建新的 dbt 项目。

请求 Body (JSON)

字段类型必填说明
namestring是项目名称，唯一，最长 255 字符
descriptionstring否项目描述

请求示例

curl -X POST http://localhost:3000/api/dbt/projects \
  -H "Content-Type: application/json" \
  -d '{"name": "analytics_project", "description": "核心分析项目"}'

成功响应 201

{
  "id": 1,
  "name": "analytics_project",
  "description": "核心分析项目",
  "status": "active",
  "createdAt": "2026-06-05T10:00:00.000Z",
  "updatedAt": "2026-06-05T10:00:00.000Z",
  "deletedAt": null
}

错误响应

400 参数验证失败

409 项目名称已存在 {"error": "Project name already exists"}

GET /api/dbt/projects

说明

获取项目列表，支持分页和状态过滤。

查询参数

参数类型默认值说明
limitnumber20每页数量，最大 100
offsetnumber0偏移量
statusstring-过滤状态：active 或 archived

请求示例

curl http://localhost:3000/api/dbt/projects?limit=10&offset=0&status=active

成功响应 200

{
  "items": [{ "id": 1, "name": "...", ... }],
  "total": 15,
  "limit": 10,
  "offset": 0
}
GET /api/dbt/projects/:id

说明

获取单个项目详情。

路径参数

参数类型说明
idnumber项目 ID

成功响应 200

返回完整项目对象（同创建响应）。

错误响应

404 {"error": "Project not found"}

PUT /api/dbt/projects/:id

说明

更新项目信息。可更新名称、描述或状态。

请求 Body (JSON)

字段类型说明
namestring新项目名称
descriptionstring新项目描述
statusstringactive 或 archived

请求示例

curl -X PUT http://localhost:3000/api/dbt/projects/1 \
  -H "Content-Type: application/json" \
  -d '{"name": "new_name", "status": "archived"}'

成功响应 200

返回更新后的项目对象。

DELETE /api/dbt/projects/:id

说明

软删除项目。项目及其所有目录和文件将被标记为已删除，后续查询不再返回。

成功响应 200

{"success": true}

错误响应

404 {"error": "Project not found"}

POST /api/dbt/projects/:id/directories

说明

在项目内创建目录。系统自动计算 path 和 depth。

请求 Body (JSON)

字段类型必填说明
namestring是目录名，仅允许字母、数字、下划线、连字符、点
parentIdnumber | null否父目录 ID，null 或不传表示根目录

请求示例

curl -X POST http://localhost:3000/api/dbt/projects/1/directories \
  -H "Content-Type: application/json" \
  -d '{"name": "models", "parentId": null}'

成功响应 201

{
  "id": 1,
  "projectId": 1,
  "parentId": null,
  "name": "models",
  "path": "models",
  "depth": 0,
  "sortOrder": 0,
  "createdAt": "...",
  "updatedAt": "...",
  "deletedAt": null
}

创建嵌套目录示例

curl -X POST http://localhost:3000/api/dbt/projects/1/directories \
  -H "Content-Type: application/json" \
  -d '{"name": "staging", "parentId": 1}'

结果：path = "models/staging"，depth = 1

GET /api/dbt/projects/:id/directories

说明

获取项目下的目录列表。可通过 parentId 过滤指定层级的目录。

查询参数

参数类型说明
parentIdnumber | null过滤指定父目录下的直接子目录

成功响应 200

返回目录对象数组。

GET /api/dbt/projects/:id/tree

说明

获取项目的完整嵌套目录树。

成功响应 200

[
  {
    "id": 1,
    "name": "models",
    "path": "models",
    "children": [
      {
        "id": 2,
        "name": "staging",
        "path": "models/staging",
        "children": []
      }
    ]
  }
]
PUT /api/dbt/projects/:id/directories/:dirId

说明

重命名或移动目录。重命名/移动时，系统自动级联更新所有子目录和文件的 path。

请求 Body (JSON)

字段类型说明
namestring新目录名（重命名）
parentIdnumber | null新的父目录 ID（移动）

重命名示例

curl -X PUT http://localhost:3000/api/dbt/projects/1/directories/2 \
  -H "Content-Type: application/json" \
  -d '{"name": "staging_new"}'

移动示例

curl -X PUT http://localhost:3000/api/dbt/projects/1/directories/2 \
  -H "Content-Type: application/json" \
  -d '{"parentId": 5}'

错误响应

400 不能移动到自身或后代目录 {"error": "Cannot move directory to itself or its descendant"}

DELETE /api/dbt/projects/:id/directories/:dirId

说明

级联软删除目录及其所有子目录和文件。

成功响应 200

{"success": true}
POST /api/dbt/projects/:id/files

说明

创建文件。系统根据扩展名自动检测 fileType，自动计算 size 和 path。支持的类型：sql, yml, yaml, md, py, csv, json, txt。

请求 Body (JSON)

字段类型必填说明
namestring是文件名（含扩展名）
contentstring否文件内容，默认空字符串
directoryIdnumber | null否所属目录 ID，null 表示项目根目录

请求示例

curl -X POST http://localhost:3000/api/dbt/projects/1/files \
  -H "Content-Type: application/json" \
  -d '{"name": "stg_users.sql", "directoryId": 2, "content": "SELECT * FROM users"}'

成功响应 201

{
  "id": 1,
  "projectId": 1,
  "directoryId": 2,
  "name": "stg_users.sql",
  "path": "models/staging/stg_users.sql",
  "content": "SELECT * FROM users",
  "fileType": "sql",
  "size": 20,
  "createdAt": "...",
  "updatedAt": "...",
  "deletedAt": null
}
GET /api/dbt/projects/:id/files

说明

获取项目文件列表，支持分页和类型/目录过滤。列表响应不含 content 字段。

查询参数

参数类型默认值说明
limitnumber20每页数量
offsetnumber0偏移量
fileTypestring-按文件类型过滤，如 sql
directoryIdnumber-按目录 ID 过滤

成功响应 200

{
  "items": [
    { "id": 1, "name": "stg_users.sql", "path": "...", "fileType": "sql", "size": 20, ... }
  ],
  "total": 50,
  "limit": 20,
  "offset": 0
}
GET /api/dbt/projects/:id/files/:fileId

说明

获取文件详情，包含完整 content 内容。

成功响应 200

返回完整文件对象（同创建响应）。

错误响应

404 {"error": "File not found"}

PUT /api/dbt/projects/:id/files/:fileId

说明

更新文件内容、名称或移动到其他目录。path 和 size 自动重算。

请求 Body (JSON)

字段类型说明
namestring新文件名
contentstring新文件内容
directoryIdnumber | null移动到新目录

更新内容示例

curl -X PUT http://localhost:3000/api/dbt/projects/1/files/1 \
  -H "Content-Type: application/json" \
  -d '{"content": "SELECT id, name FROM users WHERE active = true"}'

成功响应 200

返回更新后的文件对象。

DELETE /api/dbt/projects/:id/files/:fileId

说明

软删除文件。

成功响应 200

{"success": true}
POST /api/dbt/projects/:id/import

说明

上传 ZIP 压缩包导入 dbt 工程。系统解析 ZIP 中的目录结构和文件内容，存入数据库。dbt_project.yml 和 packages.yml 会被自动跳过。导入操作在数据库事务中执行，失败时全部回滚。

请求 (multipart/form-data)

字段类型说明
fileFileZIP 压缩包，最大 50MB

请求示例

curl -X POST http://localhost:3000/api/dbt/projects/1/import \
  -F "file=@my_dbt_project.zip"

成功响应 200

{
  "directories": 12,
  "files": 35
}

错误响应

400 文件格式错误 {"error": "Invalid file format, only ZIP is supported"}

413 文件过大 {"error": "File size exceeds limit (50MB)"}

404 项目不存在 {"error": "Project not found"}

GET /api/dbt/projects/:id/export

说明

将项目导出为标准 dbt 工程目录结构的 ZIP 文件。

请求示例

curl -O http://localhost:3000/api/dbt/projects/1/export

成功响应 200

返回 ZIP 文件下载。

响应头值
Content-Typeapplication/zip
Content-Dispositionattachment; filename="project_name.zip"

错误响应

404 {"error": "Project not found"}
